# ⚛️ React Practice

이 저장소는 **React 기초 수업**을 들으며 작성한 실습 예제들을 정리한 공간입니다.  
컴포넌트 기반 구조와 상태 관리, 이벤트 처리 등 프론트엔드 개발의 핵심을 학습했습니다.  

---

## 📌 학습
- React 프로젝트 구조 이해
- 함수형 컴포넌트 및 JSX 문법 학습
- props와 state를 통한 데이터 전달 및 관리
- 이벤트 처리 및 간단한 사용자 인터랙션 구현
- 기초적인 React Hook(`useState`, `useEffect`) 사용

---

## 📂 주요 실습 내용
- **Hello React** : 기본 출력 및 JSX 문법
- **컴포넌트 분리** : 재사용 가능한 UI 컴포넌트 작성
- **Props & State** : 부모-자식 간 데이터 전달
- **이벤트 처리** : 버튼 클릭, 입력 처리
- **간단한 프로젝트**
  - 카운터 앱
  - To-Do List
  - 간단한 회원 정보 입력 폼
